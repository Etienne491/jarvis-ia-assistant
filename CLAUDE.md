# JARVIS

## Recomendación para Claude Code

Este proyecto ya está preparado para que Claude Code lo instale y lo ejecute. Solo tiene que seguir el flujo estándar.

### Prompt sugerido

```text
Instala este proyecto en la carpeta actual. Crea el entorno virtual si no existe, instala las dependencias con pip install -r requirements.txt, copia .env.example a .env si hace falta, configura OPENAI_API_KEY si está disponible, y lanza la app con python app.py. Revisa si hay errores de dependencias y corrígelos antes de dejarlo funcionando.
```
